# Calendar Application

This is a simple calendar application built using HTML, CSS, and JavaScript. The application allows users to view a calendar, navigate between months, and highlights the current date.

## Project Structure

```
calendar-app
├── src
│   ├── index.html        # Main HTML document for the calendar application
│   ├── styles
│   │   └── style.css     # CSS styles for the calendar application
│   └── scripts
│       └── app.js        # JavaScript code for calendar functionality
└── README.md             # Documentation for the project
```

## Getting Started

To run the calendar application, follow these steps:

1. **Clone the repository** (if applicable):
   ```
   git clone <repository-url>
   ```

2. **Navigate to the project directory**:
   ```
   cd calendar-app
   ```

3. **Open the `index.html` file** in your web browser:
   - You can simply double-click the `index.html` file or open it using your preferred web browser.

## Features

- View the current month and year.
- Navigate to previous and next months.
- Highlight the current date.

## Technologies Used

- HTML
- CSS
- JavaScript
